# From-RNN-to-GAN 🚀

This repository contains Deep Learning lab experiments and practical implementations of modern neural network architectures using Python and deep learning frameworks.

## Topics Covered
- RNN vs LSTM vs GRU Performance Comparison
- LSTM for Text Classification
- Sequence-to-Sequence Models
- Attention Heatmap Visualization
- BERT Fine-Tuning for QA & Sentiment Analysis
- Variational Autoencoders (VAE)
- GANs for Image Synthesis
- Graph Convolutional Networks (GCN)

## Tech Stack
- Python
- TensorFlow / PyTorch
- Hugging Face Transformers
- NumPy, Pandas, Matplotlib
